# 🎬 Netflix Clone (Flutter)

A simple **Netflix Clone** built with **Flutter** to practice API integration.  
This app is **not** a movie streaming platform — it only displays movie details fetched from an external API.

---

## 📱 Features
- Browse movies with poster, title, and description
- View detailed information about each movie
- Clean and responsive UI built with Flutter
- API integration for dynamic movie data

---

## 🛠️ Tech Stack
- **Flutter** (UI framework)
- **Dart** (programming language)
- **REST API** (for movie data)

---
